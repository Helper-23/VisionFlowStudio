# VisionFlow Studio 软件授权与密钥签发

## 客户端激活流程

1. 客户在新电脑首次启动 VisionFlow Studio。
2. 软件在加载 VisionMaster、VisionPro、HALCON、相机和 PLC SDK 之前显示“软件激活”窗口。
3. 客户复制机器码并发送给软件供应商。
4. 供应商在内部电脑使用 `VisionFlowStudio.LicenseTool.exe`，选择私钥、填写客户机器码和授权信息，生成 `.vfslic` 文件。
5. 客户导入 `.vfslic` 或粘贴许可证内容。激活成功后授权保存到 `%LocalAppData%\VisionFlowStudio\License\license.dat`。

机器码由 Windows 机器标识和系统盘卷标识生成，不使用 IP 或网卡 MAC。修改 IP、更换普通网卡不会导致失效；把软件和许可证复制到另一台电脑则不能运行。

## 首次建立生产密钥

只需要做一次：

```text
VisionFlowStudio.LicenseTool.exe --generate-key-pair C:\Secure\VisionFlowStudio-LicenseKeys
```

会生成：

- `VisionFlowStudio.private.xml`：签发私钥，必须离线备份并限制访问，绝不能随安装包发布。
- `VisionFlowStudio.public.xml`：验证公钥，应写入 `LicenseConstants.PublicKeyXml` 后重新编译正式版。

如果丢失私钥，旧版本应用无法继续签发新许可证；如果私钥泄漏，应生成新密钥对并发布带新公钥的应用版本。

## 命令行签发

永久许可证：

```text
VisionFlowStudio.LicenseTool.exe --issue --private C:\Secure\VisionFlowStudio.private.xml --machine VFS-xxxxx-xxxxx-xxxxx-xxxxx-xxxxx-xxxxx-xxxxx-xxxxx --customer "客户名称" --edition Professional --features All --out Customer.vfslic
```

限时许可证增加：

```text
--expires 2027-12-31
```

## 发布检查

- 客户安装包需要包含 `VisionFlowStudio.Licensing.dll`。
- 不得包含 `VisionFlowStudio.LicenseTool.exe`、`VisionFlowStudio.private.xml` 或 `license-admin` 目录。
- 发布前在一台未激活的测试电脑验证首次启动会出现激活窗口。
- 用错误机器码、修改后的许可证、过期许可证分别验证均不能进入主程序。
- 使用代码混淆和 Authenticode 签名可进一步提高抗篡改能力，但任何纯软件离线授权都无法做到绝对不可破解。
